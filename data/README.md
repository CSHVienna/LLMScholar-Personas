# data/

Inputs that are tracked alongside the code. Larger artefacts (Semantic Scholar parquet, OpenAlex DuckDB, exploded LLM responses) live outside the repo and are referenced via `config.ini`.

```
data/
├── context/        Prompt scaffolding per language (instructions, locations, input).
├── models/         List of LLMs to evaluate plus their metadata.
├── annotator_agreement/   Manual labels on LLM response validity.
└── ethnicity_inference/   Manual labels on inferred researcher ethnicity.
```

## `context/{english,spanish,german}/`

Prompt scaffolding generated by `code/scripts/prompting/`:

- `instructions.json` — persona/role/task combinations (translated by `batch_params.py`).
- `locations.json` — country list (translated by `batch_params.py`).
- `input.json` — fields and subfields plus per-language `k` values (translated by `batch_params.py`).
- `all_prompts.txt` — every prompt combination, expanded from the JSONs by `batch_prompt.py`. This file is **gitignored**: it can be regenerated at any time and would otherwise add ~1.8 MB of duplicated content to the repo.

## `models/`

- `models.txt` — one model identifier per line. The list of LLMs evaluated in the experiment.
- `metadata.json` — per-model metadata: `size`, `access`, `family`, `reasoning`.

## `annotator_agreement/`

Manual labels on the validity of LLM responses (whether the output is valid JSON, refusal, etc.). Two annotators labelled an overlapping sample:

- `manual_labels_annotator1.csv`
- `manual_labels_annotator2.csv`
- `manual_validation_20.csv` — a 20-row sample shared between annotators for inter-annotator agreement metrics.
- `manual_validation_20_checked.csv` — the same sample with a third reconciled column.
- `sample_100.csv` — sampling reference used to build the labelled sets.

## `ethnicity_inference/`

Manual labels on the perceived ethnicity inferred for sampled researchers (used to validate the BERT/ethnicolr cascade):

- `manual_labels_annotator1.csv`
- `manual_labels_annotator2.csv`
- `sample_100.csv` — sampling reference.
