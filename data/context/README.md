# Data Context Directory

This directory contains the parameter files and generated prompts for multiple languages.

## Files

Each language folder contains the same five files:

### 1. `instructions.json`

Defines the persona of the LLM making the query. Contains:

- **role**: The professional role or identity of the persona (e.g., researcher, educator, healthcare worker)
- **task**: The specific task or objective the persona is trying to accomplish
- **target**: The target population for whom recommendations are being made

**Example structure:**
```json
{
  "roles": ["Director/Recruiter", "PhD student"],
  "tasks": ["seeking potential hires", "seeking an advisor"],
  "targets": ["Junior Professor", "Senior Professor"]
}
```

### 2. `locations.json`

Contains a list of countries/locations where the recommendations are relevant.

**Example structure:**
```json
{
  "countries": ["South Africa", "Germany", "Canada", "Ecuador", "Japan"]
}
```

### 3. `input.json`

Specifies the task parameters for generating recommendations:

- **k**: The number of recommendations to generate (e.g., 5, 10, 15)
- **fields**: Main categories or domains for recommendations
- **subfields**: Subcategories within each field for more specific recommendations

**Example structure:**
```json
{
  "k": [1, 5, 10],
  "fields":[
    {
      "field": "Mathematics",
      "subfields": ["Number theory", "Topology"]
    },
    {
      "field": "Computer Science",
      "subfields": ["Software Engineering", "Artificial Intelligence"]
    },
    {
      "field": "Physics",
      "subfields": ["Condensed Matter", "Education"]
    },
    {
      "field": "Biology",
      "subfields": ["Neuroscience", "Anatomy"]
    },
    {
      "field": "Sociology",
      "subfields": ["Family", "Criminology"]
    },
    {
      "field": "Psychology",
      "subfields": ["Forensic Psychology", "Social Psychology"]
    }
  ]
}
```

### 4. `all_prompts.txt`

Contains all generated prompt combinations created by combining every possible permutation of:
- Instructions (role × task × target)
- Locations (each country)
- Inputs (k × field × subfield)

This file is automatically generated by `batch_input_prompts.py` and contains the complete text of all possible prompts for the given language.

**Total combinations = (roles × tasks × targets) × countries × (k values × fields × subfields)**

### 5. `all_params_and_prompts.json`

The same prompts with their parameters, read by the collect scripts (`batch_collect_*.py`), also generated by
`batch_input_prompts.py`:

```json
[{"id": 0,
  "parameters": {"persona_context": {"role": "...", "task": "...", "location": "..."},
                 "user_request": {"k": 1, "target": "...", "field": "...", "subfield": "..."}},
  "prompt": "You are a ..."}]
```

`id` is the position of the combination and the key of the response files in `data/responses/`, so the
combination order must never change.

## Language Support

All files are available in multiple languages with identical structure. The content is translated using `batch_input_params.py`, ensuring that prompts can be generated in the user's preferred language while maintaining consistency across all language versions.

## Usage

These files serve as input parameters for the prompt generation system:

1. **Generate parameters**: Use `batch_input_params.py` to create/translate these files for each language
2. **Generate prompts**: Use `batch_input_prompts.py` to combine parameters and create specific prompt combinations
3. **Access prompts**: Reference `all_prompts.txt` for the complete list or use combination IDs to access specific prompts
4. **Collect responses**: the `batch_collect_*.py` scripts read `all_params_and_prompts.json`

## Notes

- All JSON files use UTF-8 encoding to support international characters
- The `all_prompts.txt` file can be large depending on the number of combinations
- Each language folder is independent and contains a complete set of translated parameters
