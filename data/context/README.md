# Data Context Directory

This directory contains the parameter files and generated prompts for multiple languages.

## Directory Structure
```
data/context/
├── english/
│   ├── all_prompts.txt          (generated, gitignored)
│   ├── input.json
│   ├── instructions.json
│   └── locations.json
├── german/
│   ├── all_prompts.txt
│   ├── input.json
│   ├── instructions.json
│   └── locations.json
└── spanish/
    ├── all_prompts.txt
    ├── input.json
    ├── instructions.json
    └── locations.json
```

## Files

Each language folder contains the same three tracked files plus the generated `all_prompts.txt`:

### 1. `instructions.json`

Defines the persona of the LLM making the query. Contains:

A list of personas, each with:

- **role**: The professional role or identity of the persona (e.g., Director/Recruiter, PhD student)
- **task**: The specific task or objective of that role
- **targets**: The seniorities of the researchers being asked for

**Example structure:**
```json
[
  {
    "role": "Director/Recruiter",
    "task": "seeking potential hires",
    "targets": ["Junior Professor", "Senior Professor"]
  },
  {
    "role": "PhD student",
    "task": "seeking an advisor",
    "targets": ["Junior Professor", "Senior Professor"]
  }
]
```

### 2. `locations.json`

Contains a list of countries/locations where the recommendations are relevant.

**Example structure:**
```json
{
  "locations": ["South Africa", "Germany", "Canada", "Ecuador", "Japan"]
}
```

### 3. `input.json`

Specifies the task parameters for generating recommendations:

- **k**: The number of recommendations to generate (1, 5, 10)
- **fields**: Main categories or domains for recommendations
- **subfields**: Subcategories within each field for more specific recommendations

**Example structure:**
```json
{
  "k": [1, 5, 10],
  "fields":[
    {
      "field": "Mathematics",
      "subfields": ["Number theory", "Topology"]
    },
    {
      "field": "Computer Science",
      "subfields": ["Software Engineering", "Artificial Intelligence"]
    },
    {
      "field": "Physics",
      "subfields": ["Condensed Matter", "Education"]
    },
    {
      "field": "Biology",
      "subfields": ["Neuroscience", "Anatomy"]
    },
    {
      "field": "Sociology",
      "subfields": ["Family", "Criminology"]
    },
    {
      "field": "Psychology",
      "subfields": ["Forensic Psychology", "Social Psychology"]
    }
  ]
}
```

### 4. `all_prompts.txt`

Contains all generated prompt combinations created by combining every possible permutation of:
- Instructions (each role/task pair × its targets)
- Locations (each country)
- Inputs (k × each field/subfield pair)

This file is generated by `batch_prompt.py` (only if it does not exist yet), contains the complete text of all possible prompts for the given language, and is gitignored.

**Total combinations = (role/task pairs × targets) × countries × k values × (field, subfield) pairs** — with the files above, 2 × 2 × 5 × 3 × 12 = 720 (combination ids 0–719).

## Language Support

All files are available in multiple languages with identical structure. The content is translated using `batch_params.py`, ensuring that prompts can be generated in the user's preferred language while maintaining consistency across all language versions.

## Usage

These files serve as input parameters for the prompt generation system:

1. **Generate parameters**: Use `batch_params.py` to create/translate these files for each language
2. **Generate prompts**: Use `batch_prompt.py` to combine parameters and create specific prompt combinations
3. **Access prompts**: Reference `all_prompts.txt` for the complete list or use combination IDs to access specific prompts

The LLM callers in `code/scripts/4_llmcaller/` read `data/context/<language>/all_params_and_prompts.json` from this directory; no script in this repository writes that file.

## Notes

- All JSON files use UTF-8 encoding to support international characters
- The `all_prompts.txt` file can be large depending on the number of combinations
- Each language folder is independent and contains a complete set of translated parameters
